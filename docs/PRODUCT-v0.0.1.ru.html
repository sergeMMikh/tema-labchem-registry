LabChem Registry v0.0.1

Дата выпуска: 18 ноября 2026 года
Статус: ранний MVP для внутреннего учёта запасов

LabChem Registry — приложение на Django для поиска и учёта лабораторных реагентов. Данные реагента хранятся отдельно от физических упаковок и мест их размещения.

Текущие функции

  • Поиск по названию реагента, формуле, CAS, поставщику, каталожному номеру и штрихкоду. Фильтры по лаборатории, листу источника, месту хранения и статусу; сортировка и постраничный просмотр.
  • Карточки реагентов и упаковок, доступное количество, места хранения, сроки годности, ссылки SDS и история перемещений.
  • Добавление реагента и упаковки; учёт расхода, перемещение упаковки и списание. Изменения запасов сохраняются в истории и требуют соответствующих разрешений Django.
  • Дерево мест хранения, сводные счётчики и список внимания: низкий запас, ожидающие или не найденные упаковки, отсутствие места или SDS, срок годности в ближайшие 90 дней.
  • Экспорт инвентаря в XLSX и доступ только для чтения к JSON-списку по /api/v1/reagents/ (до 100 результатов за запрос).
  • Управление пользователями и разрешениями через Django Admin. Настроены группы Viewer, Laboratory user и Administrator.

Сайт, боты и API используют одно хранилище Django. Локальная конфигурация по умолчанию использует SQLite; PostgreSQL можно настроить отдельно. OCR этикеток и автоматическое создание записей по фотографиям в эту версию не входят.

Бот Telegram

Бот Telegram предоставляет поиск по инвентарю без изменения данных. В личных чатах он принимает названия, формулы, CAS, поставщиков, каталожные номера и штрихкоды. Показывает доступные упаковки, места хранения, ссылки SDS и кнопки с пагинацией для нескольких результатов. Групповые чаты игнорируются. Можно ограничить доступ списком Telegram-пользователей.

Голосовой поиск включается отдельно и требует установленной локальной модели распознавания. Распознавание ограничено португальским и английским языками; длительность аудио — до 30 секунд, размер — до 5 МБ. Страницы результатов хранятся один час или до перезапуска процесса. На один токен запускайте один процесс long polling.

Бот WhatsApp — тестовая версия

Интеграция использует WhatsApp Cloud API Meta и тестовый номер приложения для разработчиков. Бот отвечает на входящие текстовые и аудиосообщения, ищет доступные запасы и показывает интерактивный список при нескольких результатах. Он не меняет инвентарь, не рассылает кампании и не начинает переписку самостоятельно. Разрешены только получатели, добавленные и подтверждённые в тестовой конфигурации Meta. Для рабочего использования нужно завершить подключение приложения к production и настроить рабочий номер и учётные данные. Meta ограничивает свободные ответы окном обслуживания; для сообщений, инициированных компанией за пределами этого окна, нужны одобренные шаблоны. См. обзор Cloud API и документацию шаблонов.

Webhook должен быть доступен Meta и настроен с соответствующим токеном проверки и секретом приложения. Подписи входящих запросов проверяются, повторные ID сообщений отбрасываются. Голосовой поиск необязателен: нужна локальная модель, поддерживаются португальский и английский, аудио ограничено 30 секундами и 5 МБ. Текстовый запрос — 2–200 символов; страницы поиска истекают через час или при перезапуске webhook. Дополнительно можно включить список разрешённых отправителей.

Источник данных и дата

Импортированные данные взяты из книги SharePoint 2026 Todos labs TEMA.xlsx. В требованиях к базе данных указано, что файл источника был просмотрен 21 сентября 2026 года. Последний записанный в базе импорт выполнен 16 ноября 2026 года в 15:19 по Лиссабону: импортировано 1 225 строк, пропущено 69. В книге есть лист газового инвентаря за август 2026 года; импортёр исключает более старый апрельский снимок и печатный лист шкафа для вытяжки.

Исходная книга не хранится в этом репозитории. inventory/data/inventory_export_template.xlsx — локальный шаблон экспорта XLSX, а не файл-источник. База данных хранит имя источника, время импорта, контрольную сумму и количество строк. Отдельная дата публикации или изменения Excel в базе не записана; дата обращения к источнику и дата импорта выше — разные факты.
