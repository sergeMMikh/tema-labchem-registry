# Поиск реагента по фотографии этикетки

Отправьте боту Telegram или WhatsApp чёткую фотографию этикетки банки. С помощью OpenAI бот считывает название, CAS, каталожный номер и производителя, затем ищет реагент в базе TEMA. Приоритет имеют совпадение CAS, точный каталожный номер и однозначное точное название. Если запись найдена, бот показывает реагент, упаковки, количество и местонахождение; к сайту Sigma-Aldrich он не обращается.

Если записи в базе нет, бот ищет продукт в каталоге Sigma-Aldrich. Когда сайт отвечает, бот показывает заголовок и описание страницы, а также прямую ссылку. Если прямой доступ не работает, поиск OpenAI только по официальным страницам Sigma-Aldrich пытается получить сведения с указанием источника. Если оба способа недоступны, бот сообщает об этом и всё равно даёт ссылку. При нечитаемой этикетке нужна более чёткая фотография; отсутствующие CAS и сведения о продукте бот не выдумывает. Поиск не меняет данные склада.

## Настройка и ограничения

Задайте `OPEN_AI_KEY` в локальном `.env`; `OPEN_AI_VISION_MODEL` (по умолчанию `gpt-4.1-mini`) и `OPEN_AI_SEARCH_MODEL` (по умолчанию `gpt-5.4-mini`) необязательны. После изменения переменных перезапустите процесс Telegram и веб-процесс WhatsApp. Telegram принимает фото, WhatsApp — изображение через настроенный webhook. Размер загружаемого изображения — до 10 МБ. Изображение уменьшается до 1800 пикселей, преобразуется в JPEG и передаётся OpenAI для распознавания. Не отправляйте конфиденциальные этикетки, если такая внешняя обработка недопустима. Использование API OpenAI для изображения и веб-поиска может быть платным. Списки разрешённых пользователей ботов действуют и для фотографий. Ограничения тестового номера WhatsApp сохраняются.

Страницы Sigma-Aldrich могут быть недоступны или изменить структуру; тогда бот даёт ссылку, не утверждая, что результат каталога подтверждён. Качество распознавания зависит от читаемости этикетки. Перед использованием в лаборатории сверьте результат с банкой.

Источники: [ввод изображений в OpenAI API](https://platform.openai.com/docs/guides/images-vision) · [каталог Sigma-Aldrich](https://www.sigmaaldrich.com/PT/en/search/acetone?focus=products&term=acetone&type=product).
